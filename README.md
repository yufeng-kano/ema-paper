## What you get

- **Clean text from every page**: columns, tables, formulas and scans, with each figure kept in place.
- **Translation under each paragraph**: one command, `/translate`. The original stays above, your language below.
- **An agent that reads the pages and the web**: ask about a sentence, a section or the whole paper. It searches the web and the literature, reads links and saves what it finds into your files. On Pro it runs code in a sandbox.
- **Notes beside the paper**: excerpts and section links that jump back to the source. Drag an answer in to keep it.
- **Every file, kept**: upload anything, not only PDFs. Folders, a Trash, and a revision you can undo for every change.
- **Works with Claude and your scripts**: add the MCP connector, or call the REST API.

## Pricing

**Free to start**, with credits every month. The model is included: no API key to bring, no card to enter. Pro adds a sandbox, more credits and storage, and top-up packs when you run out. [See plans](https://ema-paper.yuufeng.com/en/pricing)
