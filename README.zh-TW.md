## 你會得到

- **每一頁都變成乾淨的文字**：多欄排版、表格、公式、掃描件都行，圖留在原位。
- **譯文接在每段下面**：一個指令 `/translate`。原文在上，譯文在下。
- **agent 看得到頁面，也看得到網路**：問一句、一節或整篇都行。它能搜尋網路和論文、讀連結，把找到的檔案存進你的檔案庫。Pro 還能在沙盒裡執行程式。
- **筆記就在旁邊**：摘錄和章節連結，點一下跳回原文。agent 的回答拖過來就能留下。
- **每個檔案都留著**：什麼檔案都能上傳，不只 PDF。有資料夾、垃圾桶，每次修改都能復原。
- **接得上 Claude 和你的程式**：加入 MCP 連接器，或呼叫 REST API。

## 定價

**免費開始**，每月都有點數。模型費用已含在內，不用自備 API 金鑰，也不用綁卡。Pro 有沙盒、更多點數和空間，用完還能加購。[看方案](https://ema-paper.yuufeng.com/zh-TW/pricing)
