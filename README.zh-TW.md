## 你會得到

- **每一頁都變成乾淨的文字**：多欄排版、表格、公式、掃描件都行，圖留在原位。
- **譯文接在每段下面**：一個指令 `/translate` 就好。
- **有問題直接問 agent**：它看得到原始頁面，問一句、一節或整篇都行。
- **筆記就在旁邊**：摘錄和章節連結，點一下跳回原文。
- **每次修改都留著**：資料夾、垃圾桶，每個改動都能復原。
- **接得上 Claude**：加入 MCP 連接器，或呼叫 REST API。
